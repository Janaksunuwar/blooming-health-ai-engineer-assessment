# Blooming Health Senior AI Engineer Assessment

This repository contains work for the Blooming Health Senior AI Engineer take-home assessment.

The assessment has three independent problems:

1. Q1: Capacity planning for 10,000 outbound AI voice calls within a 30-minute window.
2. Q2: Architecture for keeping a long-running AI voice agent accurate across a 40-minute Medicaid renewal workflow.
3. Q3: A runnable Python evaluation harness for determining whether an AI agent successfully completed a healthcare workflow from a transcript and captured field values.
